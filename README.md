# ChessDep

Онлайн-шахматы (PvP) с элементами казино:
- **деп** — в свой ход можно рискнуть фигурой: с шансом `ценность_из / ценность_в` она превращается в более ценную, иначе сгорает (не больше 1 депа за ход и 10 за партию);
- **скины** фигур и досок, выпускаемые коллекциями, **кейсы**, **апгрейд** скинов, **маркет** между игроками, **подарки**.

Валюта ◈ только виртуальная: не покупается и не выводится. Сервер — единственный источник истины: в браузере хранится только cookie сессии, все шансы и броски считаются на сервере.

Как всё устроено: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md). Исходное ТЗ: [`docs/TZ.md`](docs/TZ.md).

## Требования

- Linux
- Docker и Docker Compose v2

Больше на хосте ничего не нужно: база, Redis и всё остальное поднимаются в контейнерах.

## Запуск

```bash
cp .env.example .env      # поменяйте POSTGRES_PASSWORD (и пароль в DATABASE_URL)
make up                   # сборка и запуск, миграции применяются автоматически
```

Сайт: `http://localhost:8080`.

Первый администратор назначается только из консоли (через сайт роль не выдать):

```bash
make make-admin LOGIN=ваш_логин
```

Остановить: `make down`. Данные (база и Redis) лежат в Docker-томах и переживают перезапуск.

## Как выпустить новые скины

Набор — это перечень коллекций и досок. Коллекция — 12 фигур одного стиля (6 белых и 6 чёрных). Коллекций и досок вне набора не бывает.

Админка → «Наборы»:
1. Создать набор (черновик, игроки его не видят).
2. Добавить коллекции (таблица из 12 фигур: редкость, ценность, цвет) и доски (редкость, ценность, цвета клеток).
3. «Выпустить». Добавлять в выпущенный набор нельзя — новое содержимое выходит новым набором. Редкость после выпуска не меняется.
4. «Снять с выпуска» — все кейсы с его скинами снимутся с продажи; выпавшие скины и купленные кейсы остаются у игроков.

Админка → «Кейсы»:
1. Создать кейс: по набору, по коллекции или особый (любые скины). Можно задать тираж и окно продаж.
2. «Автовеса» (по редкости, как в CS) или «Дропы вручную».
3. «Опубликовать» — кейс появится в магазине. После тиража или конца окна он сам уходит из продажи. Купленный кейс лежит в инвентаре, пока игрок его не откроет; его можно продать или подарить.
4. Внизу вкладки — пул ежедневной награды: какие кейсы и с какими весами получает игрок после 3 побед за день.

У каждого игрока есть базовые скины (набор «Базовый»): они надеты по умолчанию, их нельзя продать, подарить и апгрейдить. Без скинов на всех 12 фигурах и доске в бой выйти нельзя.

## Настройки экономики

Меняются в админке на вкладке «Настройки», без перезапуска. Среди них: стартовый баланс, число побед для ежедневной награды, награды за партии, множитель шанса депа, комиссия апгрейда и маркета, задержка передачи предметов. Полный список и границы значений — в `docs/TZ.md`, раздел 5.

## Доступ с другой машины

Добавьте адрес, по которому открывают сайт (например `http://192.168.1.10:8080`), в `ALLOWED_ORIGINS` в `.env` через запятую и выполните `make up`. Запросы с других адресов сервер отклоняет (защита от CSRF).

## HTTPS

nginx сам выбирает режим при старте: если в `certs/` лежат `fullchain.pem` и `privkey.pem` — HTTPS на `HTTPS_PORT` (по умолчанию 8443) и редирект с http; если нет — только http.

1. Сертификаты:
   - для разработки: `bash scripts/gen-dev-cert.sh` (самоподписанный, браузер покажет предупреждение);
   - для сервера: положите настоящие `fullchain.pem` и `privkey.pem` (например, от Let's Encrypt) в `certs/`.
2. В `.env`: `COOKIE_SECURE=true` и добавьте адрес в `ALLOWED_ORIGINS`, например `https://localhost:8443` или `https://example.com:8443`.
3. `make up && docker compose restart nginx`.

## Устройство

```
backend/    FastAPI + SQLAlchemy + Alembic; app/chess_engine — правила депа поверх python-chess
frontend/   чистые HTML/CSS/JS-модули без сборки
nginx/      статика, прокси API и WebSocket, заголовки безопасности
docs/       ТЗ и аудит старого фронта
tasks/      задания, по которым писался код
legacy/     старый фронт — только как визуальный референс
```

Контейнеры: `nginx` (наружу только он), `api`, `worker` (часы, флаги по времени, матчмейкинг), `migrate`, `postgres`, `redis`.
