# Общие правила для всех задач polish-1

- Работай ТОЛЬКО в своём worktree (путь указан в задаче). НИКОГДА не заходи и не переключай ветки в /home/nik/PycharmProjects/ChessDep.
- Меняй ровно те файлы и места, что перечислены. Всё остальное трогать запрещено. Никаких «улучшений» сверх ТЗ.
- Стиль кода — как в окружающем коде (комментарии по-русски, такая же плотность).
- Фронт: DOM только через `h()` из `js/dom.js` и `textContent`; без `innerHTML`, `Math.random`, `localStorage`/`sessionStorage`, инлайн-стилей; динамические стили — только `el.style.setProperty(...)`.
- Если что-то не сходится с ТЗ (нет такого кода, тест падает не по твоей вине и т. п.) — остановись, ничего не придумывай, опиши проблему в итоговом отчёте.
- В конце: `git add -A && git commit -m "<короткое описание по-русски>"` в своём worktree (ветка уже создана). Итоговый отчёт: что сделано, вывод команды проверки (последние строки).
